# Hackathon Demo — 3 Minutes

## 1. Start with the user

Open **Is Everything Okay?**.

Say:

> “Cybersecurity tools normally expect people to understand security logs. We are building the layer that explains those logs for them.”

## 2. Show the everyday question

Open **When I Was Away**.

Ask:

> “What happened while I was away?”

Show the failed access attempts and the reconstructed activity window.

## 3. Show the security-flight-recorder story

Open **USB Activity**.

Walk through:

```text
USB → process → child process → network → persistence
```

Then open the reconstructed incident.

## 4. Show explainability

Point to:

- Observed
- Inferred
- Unknown
- Risk factors
- Event IDs

Say:

> “The system does not need to call something an attack just because it looks unusual. It shows what it actually observed, what it inferred, and what remains unknown.”

## 5. Show the AI interface

Ask:

> “What did the USB do?”

Then:

> “Why was this flagged?”

Finally:

> “Show me the evidence.”

## 6. Mention the experimental prediction feature

Open **Attack Prediction** and say:

> “Once behavior has been reconstructed, we can experiment with predicting a possible next stage. This is intentionally marked experimental and is not treated as proof that an attack will happen.”

## 7. Close

> “The goal is to take endpoint security from something only security professionals can interpret and make it understandable to everyone, while keeping the underlying evidence available for people who want the technical detail.”
